# @pyqvault_ learnings log

Kept apart from @lws.pune's log (`learnings.md`) since 2026-10-20 (founder): a different audience (Class 11–12
science, not NDA), a different format ("Physics / Chemistry, visualised"; maths until 2026-10-20) and different numbers. Same method:
every lesson from real numbers becomes a **testable idea**: what we saw, what we think it means, which reel tests it,
and the result. Update **Result** and **Status** after each reel's 48 h and 7 d numbers (Insights tab of GoPost, or
`npm run insights -- --org=lws-pune` → `analytics/pyqvault-reels-<date>.csv`). A rule moves into `pyqvault-insta.md`
(house settings) only once it's **Confirmed** or the founder makes it one.

All three logs (this one, `learnings.md`, `soundmind/learnings.md`) share **one numbering** (L1, L2, …), so a number always means one lesson. The next new lesson is **L58**,
in whichever log it belongs to. How reels are made is in `pyqvault-framework.md` (F-numbers); each of its points
names the lesson that measures it.

**Filled by script, not by hand (founder, 2026-10-22).** The reel's age at its reading is in brackets: "(48 h)" is GoPost's
write-once 48 h reading, the one the idea score and the virality predictor learn from; a younger reel shows its latest
numbers until its 48 h reading exists. **Every analysis, in this order:**
1. `cd publisher && npm run insights -- --org=lws-pune && npm run results -- --org=lws-pune --project=pyqvault-insta`
   (fresh numbers, then each reel's 48 h / 7 d readings → `analytics/reel-results-pyqvault-insta.json`, local only)
2. `node reels/tools/results-sync.js` (copies them into this table; a new reel gets its row)
3. `node reels/tools/virality.js --update` (old predictions get their outcome, the predictor's weights move as its rule
   allows, the run is logged in `virality-log.md`)
4. `node reels/tools/topic-scores.js pyqvault --calibrate` (the idea score's weights; log the run in `pyqvault-ideas.md`)

Every new reel is predicted before it's queued (`visual-reel-workflow.md` step 7, framework F30).
