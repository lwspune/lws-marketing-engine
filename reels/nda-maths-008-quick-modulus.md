## The question

> If x² − 2x cos θ + 1 = 0, then what is the magnitude of x?
> (a) −1  (b) 0  (c) 1  (d) √2

## The working (checked)

- Discriminant D = 4cos²θ − 4 = −4sin²θ ≤ 0, so the roots are a conjugate pair x, x̄ (a real double
  root ±1 when cos θ = ±1).
- Product of roots = c/a = 1 = x · x̄ = |x|², so **|x| = 1** → **(c)**.

**Traps:** (a) −1: a magnitude is never negative · (b) 0: x = 0 gives 1 = 0, not a root · (d) √2: a
guess (|1 + i|), nothing in the equation gives it.
